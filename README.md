# Sprint Timer Project - *Raul 3000*

In this repository there's code and a latex report for a small automation project developed for highschool use.

In the described project I developed a **small Raspberry pi powered machine that uses two motion sensors to measure sprint times** for highschool evaluation in PE.

This project was called **Raul 3000** in honor of my friend Raul who gave me the idea and challenged me to do it. This project was also part of his master's thesis in Sport Science as a part of his academic internship at a public school.

## Repo Guide

This repo has **three folders**: report, and in the folder code: [test](code/test/README.md) and [main](code/main/README.md).

### Report

---

Has the latex file and the pdf file with the report of the project. This report was used for academic purposes and has little interest for replication of the project, but it has a description of the development process.

### Test

---

Has files with development code that was use during development to test individual functions or preliminary states. It can still be useful for testing. For more info go here [test](code/test/README.md).

### Main

---

Has the main code and two custom libraries needed to run the project. For more info go here [main](code/main/README.md).
